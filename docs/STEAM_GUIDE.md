## Section 1 — About this mod

I made a small MelonLoader mod for the full PC game. It adds a nine-tab menu inside the game, so there is no separate trainer application to run. It's intended for experimenting with single-player mechanics and progression.

The menu is **currently in French**. I'll include English translations of the main tabs below.

The mod is free and unofficial. It's not made or endorsed by the game's developer.

## Section 2 — Download and requirements

- You need the **full Steam version** of Can 'Em All on Windows (not the demo).
- Install the official [MelonLoader 0.7.3](https://github.com/LavaGang/MelonLoader/releases/tag/v0.7.3).
- Download **CanEmAll-Trainer-v7.2.0-Windows.zip** from this project's [GitHub Release](https://github.com/BreezeDelegate/can-em-all-trainer/releases/tag/v7.2.0).

**Back up your game save before using a trainer.** It changes money and progression and can affect achievements.

If Steam hides the link, search GitHub for `BreezeDelegate/can-em-all-trainer` rather than following an unfamiliar mirror. Do not use shortened or disguised links.

## Section 3 — Install the trainer

1. In Steam, right-click **Can 'Em All → Properties → Installed Files → Browse**.
2. Install MelonLoader for the **full game's executable** in that folder. Start the game once, then close it.
3. Open the downloaded ZIP and extract its contents **into the game's root folder**.
4. Confirm this file exists: `Mods/CanEmAllFullMod.dll`. The ZIP already contains the `Mods` folder.
5. Start the game. Press the **physical key immediately beneath Esc and to the left of 1**. On a French AZERTY keyboard it's **²**; on many QWERTY keyboards it's the backtick/tilde key.

Press the same key again to close the menu.

## Section 4 — What you can change

| French tab | English | Main functions |
| --- | --- | --- |
| Joueur | Player | Money, stamina, speed, jump, damage |
| Créatures | Creatures | Spawn available creature models |
| Canettes | Cans | Spawn cans using the game's pool |
| Armes | Weapons | Unlock/select weapons, compatible gun ammo |
| Chances | Chances | Combat and production probabilities |
| Monde | World | Time, conveyor and factory settings |
| Progression | Progression | Unlock standard skill-tree upgrades |
| Sauvegarde | Save | View save statistics |
| Casino | Casino | Slot-machine odds when available |

There's also an **Équipement** (Equipment) section under **Monde** for turret ammo supply, vacuum capacity and throw rate, and flamethrower range.

**Controls:** Click the money field to enter an amount and press Enter to apply. Shift+click on numerical +/- controls changes the value by ten instead of one.

## Section 5 — Important limitations

- The in-game menu is currently in French.
- The **casino is not force-unlocked**. Its controls only appear when the machine is available in your save.
- The trainer **does not give permanent prestige upgrades or unlock the final exit**.
- Automatic ammo supply avoids weapons with reload/animation restrictions, such as the rocket launcher and melee weapons.
- The game may change after updates; compatibility isn't guaranteed.
- This mod has been tested, but not every weapon/action/scene combination has been manually verified.

## Section 6 — Uninstall / get help

Close the game and delete `Mods/CanEmAllFullMod.dll`. This removes the trainer, **not** any changes you've already made to your game save.

If a feature breaks, include your game version, MelonLoader version, relevant log lines from `MelonLoader/Logs`, and the steps needed to reproduce it.
