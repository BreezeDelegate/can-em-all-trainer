# Steam guide updates for trainer v7.4.2

Steam guides use BBCode. Paste the content below into the named Steam guide section, not into the section-title field.

## Short description (replace only if desired)

```text
An unofficial in-game trainer for Can 'Em All. Install with MelonLoader, open with F8 or the key below Esc, and use a bilingual nine-tab menu with gameplay, casino and progression tools.
```

## Section: Installation

```text
[list]
[*]In Steam, right-click Can 'Em All, then select Properties > Installed Files > Browse.
[*]Install MelonLoader 0.7.3 for the game's executable in that folder. Run the game once, then close it.
[*]Download the latest trainer ZIP from the Download section.
[*]Extract the ZIP directly into the game's main folder. Allow it to replace the previous trainer DLL if asked.
[*]Check that Mods/CanEmAllFullMod.dll exists.
[*]Launch the game. Installation complete!
[/list]

[b]Updating from an older trainer version?[/b] Close the game and replace the existing Mods/CanEmAllFullMod.dll with the one from the new ZIP. Your save and trainer preferences remain in their own locations.
```

## Section: How to open the menu

```text
[b]Press F8[/b] to open or close the trainer.

You can also use the original physical key directly below Esc (² on French AZERTY keyboards, backtick/tilde on many QWERTY keyboards).

Use English or Français with the flag icons in the top-right corner to change the menu language. The selection is saved.

Click the money field to edit it, then press Enter or Apply. Ctrl+A and Ctrl+V are supported. Shift + click on numerical +/- buttons changes the value by 10.
```

## Section: Main features

```text
[list]
[*][b]Player:[/b] Money, infinite stamina, movement, jumping, damage.
[*][b]Creatures:[/b] Choose and spawn available creature types.
[*][b]Cans:[/b] Spawn standard cans.
[*][b]Weapons:[/b] Unlock and equip weapons, add ammo, refill.
[*][b]Chances:[/b] Modify combat and production probabilities.
[*][b]World:[/b] Adjust day/night, truck count, conveyors and equipment.
[*][b]Progression:[/b] Purchase ordinary upgrades or send the factory-sale offer email.
[*][b]Save:[/b] View statistics and set 100,000 children fed to request the related Steam achievement.
[*][b]Casino:[/b] Send the casino unlock email and adjust slot-machine odds.
[/list]

[h3]Unlocking the Casino and Factory Sale[/h3]

[b]Casino:[/b] Open the trainer's Casino tab and click Send Casino Email. On the in-game computer, open the Feeling Lucky email and select Accept.

[b]Sell Your Factory:[/b] Open the trainer's Progression tab and click Send Factory Offer. On the in-game computer, open An Offer You Can't Refuse and select Accept.

[b]Note:[/b] Near Miss / Almost Win (Still Lose) controls how often a losing spin looks close to a win. It does not increase the actual winning chance.
```

## Section: Known limitations

```text
[list]
[*]Full Windows game only. The trainer is not designed for the demo.
[*]Casino and factory-sale emails must still be accepted in the game's email interface.
[*]Permanent upgrades are purchased through the game's Prestige system, not granted by the trainer.
[*]The final exit upgrade is not unlocked directly.
[*]Setting a progress counter requests its Steam achievement, but Steam still controls whether the achievement is awarded.
[*]The mod can change save progression. Make a backup before using irreversible game actions.
[/list]
```
