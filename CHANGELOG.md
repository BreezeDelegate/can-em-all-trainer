# Changelog

## 7.3.0 — 2026-11-02

- English translations for the nine menu tabs, controls, confirmations, hints and status messages.
- One bilingual DLL with instant EN / FR selection beside Close; new installations default to English.
- Language preference stored in the existing configuration; French remains available.
- Added language unit tests and native in-game localization smoke coverage.
- No changes to gameplay or upgrade mechanics.

## 7.2.0 — 2026-11-02

Initial public GitHub release of the full-game trainer.

- Native in-game Unity UI with nine tabs and game-sourced sprites.
- Creature/can spawning, money and progression controls.
- Equipment settings: turret ammo, vacuum capacity/throw cadence and flamethrower range.
- More selective automatic ammunition supply; avoid interfering with melee and rocket reloads.
- Direct click-to-edit money field, Shift+click stepping and improved tab labels.
- More input gating while the trainer menu is open.
- Limits: French-language UI, no casino unlock, no prestige or final exit unlock.

See [installation](README.md) and [Steam guide draft](docs/STEAM_GUIDE.md).
